# 沃飞长空 AE200：技术、场景与市场可行性

以「飞行汽车技术基础」案例体的版式，对沃飞长空（AEROFUGIA）AE200 系列倾转旋翼 eVTOL 做一次证据分级的深度评估。

- **在线页面**：`index.html`（单页，含全部图表与交互）
- **证据截止**：2026-11-24
- **版本**：1.0

## 内容结构

| 02 公司与项目路径 | 吉利体系、融资、产能、订单结构、CCAR-135 资质辨析 |

## 技术说明

- 纯静态单页，无构建步骤、无外部 JS/CSS 依赖。
- 中英双语切换（右上角 `EN / 中文`），使用 `localStorage` 记忆选择。
- 图表为内联 SVG / HTML 表格；照片为沃飞长空官方媒体素材，仅用于识别研究对象。
- 响应式：桌面三栏（目录 / 正文 / 证据栏），≤1120px 收起目录，≤900px 单栏。
